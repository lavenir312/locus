# 门禁十四条

`scripts/gate.py` 读笔记、台账、原文三样，跑十四条检查。全过才准交付。任一条不过，退出码 1。

## 原（4 条）

| 编号 | 检查 | 不过怎么办 |
|---|---|---|
| AR1 | 每条结论都标了来源等级（原意/事实/推断/存疑） | 给每条 claims 补 `type` 字段，正文对应处加标注 |
| AR2 | 引文逐字能在原文找到 | 找到那处引号，改成逐字；改不动就去掉引号写成转述 |
| AR3 | 每条结论的 sources 指向真实存在的段号 | 段号写错的回原文重找 |
| AR4 | 定位覆盖 ≥20% 的段落 | 通读一遍补锚点，通常漏的是过渡段和尾注段 |

## 全（3 条）

| 编号 | 检查 | 不过怎么办 |
|---|---|---|
| CO1 | 逐块覆盖 ≥90% 段落（blocks + claims 的 sources 合并算） | 把没进主张的段落补进 blocks，标 no-content 并写理由 |
| CO2 | 封闭清单 expected 与 found 相等 | 数目不符回原文重数，**不要改数字迁就笔记** |
| CO3 | 台账有 gaps 字段 | 即使没有缺口也要写空数组并说明 |

## 术（3 条）

| 编号 | 检查 | 不过怎么办 |
|---|---|---|
| SH1 | 术语表 ≥5 条 | 本书的核心概念通常 5–20 个，少于 5 说明没做术语梳理 |
| SH2 | 每条术语有 term/def/sources | 补界定与出处 |
| SH3 | 术语能在原文找到，或属通行学术术语 | 改学界通用名；确属材料外的，加进 lexicon 并标「材料外」 |

## 易（4 条）

| 编号 | 检查 | 不过怎么办 |
|---|---|---|
| YI1 | 有分层概述（L1 一句话或开篇短文） | 补一句「这章在讲什么」 |
| YI2 | 篇幅 800–9000 汉字 | 太短说明没展开，太长先砍重复与引文块 |
| YI3 | 无 30 字以上重复片段 | 删掉后出现的那一次 |
| YI4 | 图的边不靠纯编号标签 | 把「①→②」改成写出两端的文字 |

## 为什么是这十四条

不是越多越好。每一条都对应一个真实发生过的失败：

- AR2 对应 dsh-deepread 把设问改写成判断还加了引号。
- CO2 对应摘要型工具把「27 条尾注」压成「若干尾注」。
- SH3 对应没人做的事——五个仓库都没有术语校验，这是本工具补的。
- YI3 对应长笔记常见的「同一个论点在引言、正文、结语各说一遍」。

## 用法

```
python scripts/gate.py --note note.md --ledger ledger.json --src work/012.md --json gate.json
```

`--json` 输出的结果可以留档，下次换模型重跑时对比哪一条退化了。
