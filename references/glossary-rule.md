# 术语规则（术）

「术」只有一条底线：**读者在别处查得到这个词，而不是只能在你这里查**。具体分四件事。

## 一、用学界通用名，不用自造比喻

判断一个词能不能用，问三句：

1. 这个词在文献里出现过吗？（不是在你上一篇笔记里出现过）
2. 换个作者会不会用同一个词指同一件事？
3. 去掉它的比喻成分，还剩下概念吗？

三条都答"是"才用。反例：「看的角度装置」应写「叙事视角」；「官民共谋的心理机制」若原文没有这个提法，应写「官民共享的国民性」并标【推断】。

## 二、术语首次出现给一句界定

格式：`术语（一句界定，出自 pNNN）`。界定讲「是什么」，不讲「很重要」。

- 好：「官本位——把官场职位当作社会资源与价值中心的观念结构（p008）」
- 坏：「官本位，一个非常深刻的概念」

界定不得为通俗牺牲边界。比如「国民性」不能写成「民族性格，就是大家的脾气」，那是把概念换成了比喻。

## 三、专名首次出现给身份

- 人名：给身份或年代。第一次写「钱谷融《论"文学是人学"》」，不要只写「钱谷融认为」。
- 书名：给作者。第一次写《篇名》（作者，发表年）。
- 英文缩写：给全称。第一次写 PCB（印制电路板），后文才可只用缩写。

## 四、语境分离

术语在材料里怎么用，和它在学界一般怎么用，是两件事。

- `context` 只写材料怎样使用该词，可以引一句原文。
- 材料之外的含义另起一句，标「材料外」。
- 材料没有界定的词，不要替它界定完再当成作者的意思。

例：同一章里，「结构」既指文本的组织方式，又指社会结构。前者是作者在本章反复用的意思，后者属于学科通名、材料并未在此意义上使用。两者各有出处，要分开列，不能合成一条。若材料只用了其中一义，另一义须标「材料外」。

## 术语表怎么写

每条七个字段，缺一不可：

```json
{
  "term": "官本位",
  "en": "official-centrism",
  "def": "把官场职位视为社会资源与价值中心的观念结构",
  "context": "作者用它概括晚清谴责小说共同的问题意识（p008）",
  "related": ["国民性", "人的文学"],
  "sources": ["p008", "p009"],
  "first": "p008"
}
```

`first` 必须是 sources 里最早的那段。

## 机器校验

```
python scripts/audit.py terms --note note.md --src work/012.md
```

脚本做三件事：把笔记里加粗的短语、引号内短词、《》书名、英文缩写全部当候选；逐个回原文找；原文没有又不在通行术语表（`audit.py` 内置，可用 `--lexicon` 追加）的，判为「需核查」。

判为需核查不等于错。两种情况可以放行：

1. 确实是学界通名，只是原文没用这个词——把它加进 `--lexicon` 文件，并在笔记里标「材料外」。
2. 是你自己的概括——改成【推断】并落到一句原文上，不要让它看起来像术语。

## 常见病

- 同一概念前后换名字（「官本位」和「官僚本位」混用）——选一个，全文统一。
- 把作者的修辞当术语（「人血馒头」是意象，不是概念，不该进术语表当分析工具）。
- 术语堆密度过高，一段里五个概念没有一个解释——读者被术语挡在门外，违反「易」。
