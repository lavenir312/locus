# 两遍回读（原 + 全 的最后一道）

写完正文必须回读两遍，**不许合成一遍**。合成之后人只会做「查错」，查漏永远排在后面然后被跳过。两遍要分别留记录。

## 第一遍：查错

逐条过，每条都要给出「过」或「改了」。

1. **引文逐字**。每处引号回原文找，一字不差；找不到就改成转述并去掉引号。
2. **锚点指涉**。每个 `(pNNN)` 打开那一段，看里面真有这句意思。段号对但内容不对，是最容易犯的错。
3. **推断有没有被写成原意**。凡是"作者认为""作者主张"后面的句子，回原文确认是断言不是设问。
   - 高频陷阱：原文是「是因为 A，还是因为 B？」这种两难设问，笔记容易写成「作者认为 A」。
4. **数字与年份**。页数、卷期、生卒年、时间跨度逐个核。版本信息尤其要看：同一章引同一本书可能用了两个版次。
5. **专名写法**。人名、书名、机构名与原文一致；异体字、简称不擅自统一。
6. **转引标注**。作者引的钱理群、竹内好、阿城等，是「原书如此转引」，不是原始文献已核。这一层要写明。
7. **问句还是判断**。作者的设问不能压成结论，这一条单列，因为它最能改变意思。
8. **图上的边**。每根箭头回原文找依据，找不到就删。

## 第二遍：查漏

1. **封闭清单点数**。几层定义、几个阶层、几条尾注、几项条件，逐个数，与登记数比对。
2. **尾注/脚注里有什么**。正文没提但注里有的内容，往往是最有信息量的部分（版本差异、改词经过、史料出处）。
3. **原文自相矛盾处**。同一事实在章内出现两次且不一致，要标出来，不替它抹平。
4. **材料自身的限定**。作者说"很少有人统计讨论"，但他自己给统计了吗？没给就要写明这是定性观察。
5. **章节结构有没有被压平**。原文的三节是递进还是并列？标题本身就是论证的一部分，别当装饰。
6. **读者的疑问**。读到某处会问"那为什么"，正文有没有回答；没回答就写进「作者留下的问号」。

## 记录格式

```json
"review": {
  "errorPass": [
    {"id": "F-01", "finding": "尾注[7]标1981版、[10]引同篇标2005版，版次混用", "action": "分别在台账登记，不合并"}
  ],
  "omissionPass": [
    {"id": "M-01", "finding": "p033「狂人最后也赴某地候补」初稿漏收", "action": "补入正文"}
  ]
}
```

## 什么不算回读

- 「已逐段核对，无误」——没有具体发现，等于没做。
- 只读了摘要和自己写的正文，没回原文。
- 把查错和查漏写成一句话：「已复核并修正若干处」。
- 发现的问题只在心里改了，台账没记。下一轮（换模型、换版本、别人接手）无法复查。
